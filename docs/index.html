02 / Engineering foundation

A transparent model, not a black box.

ThermoDC uses a lumped sensible heat balance and synthetic rack mixing factors. Each control changes interpretable calculations. The full Python implementation, SQL experiments, CI tests and assumptions are available in the GitHub repository.

Limitations: This is a steady-state educational model—not CFD, transient failure prediction, real facility monitoring, or a safety-rated engineering tool.
